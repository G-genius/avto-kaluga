# 🚗 АвтоКалуга

Telegram-бот для автомобилистов Калуги.

## ⛽ Возможности

- Проверка наличия топлива на АЗС
- Отправка отметок о наличии топлива
- АИ-92, АИ-95, АИ-98/100 и дизель
- Информация об очередях
- Поиск ближайших АЗС
- Отчёты по АЗС
- Автоматические отчёты в Telegram-канал
- Чат автомобилистов
- Административная панель
- Управление АЗС
- Автоматические фоновые задачи

## 📁 Структура проекта

- `bot.py` — основной Telegram-бот
- `database.py` — работа с базой данных
- `auto_posts.py` — автоматические публикации
- `report_channel.py` — отчёты и публикации
- `scheduler.py` — планировщик
- `nearby_stations.py` — поиск ближайших АЗС
- `rating.py` — рейтинг данных
- `subscription.py` — проверка подписки
- `stations_data.py` — данные АЗС
- `admin_add_station.py` — добавление АЗС
- `admin_edit_station.py` — редактирование АЗС
- `admin_station_status.py` — управление статусом АЗС
